## 🚀 Featured Projects

### [Transaction-Safe Real-Time Bidding Platform](https://github.com/GurpreetKukkar15/Transaction-safe-bidding-platform)
PostgreSQL-backed auction service comparing pessimistic row locking vs optimistic version-based concurrency control. 63-test suite; 2M bids benchmarked — optimistic control hit ~1.9K req/s with p95 latency cut from ~30ms to ~24ms.

### [DocLens — Multi-Document RAG System](https://github.com/GurpreetKukkar15/DocLens)
Upload PDFs, ask questions, get per-document answers with page-level citations plus cross-document theme synthesis. RAG pipeline with Qdrant vector search and two-stage Groq/Llama 3.3 70B generation. [Live demo](https://doc-lens.vercel.app)

### [AlgoVault — LeetCode Tracker](https://github.com/GurpreetKukkar15/AlgoVault)
Full-stack app for logging LeetCode problems with SM-2 spaced repetition flashcards and AI-powered pattern detection via Groq/Llama 3.1. JWT auth, analytics, paginated search. [Live demo](https://algo-vault-pi.vercel.app)

### [concurrent-kv-store](https://github.com/GurpreetKukkar15/concurrent-kv-store)
Concurrent, persistent TCP key-value store built from scratch in C on Linux — custom hash table, thread pool, and write-ahead persistence.
